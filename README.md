# Слойка (Slojka)

**[English version → README.en.md](README.en.md)** · **[Video →](https://www.youtube.com/watch?v=1RKRtRgzE24)**

[![License: GPL-3.0](https://img.shields.io/badge/License-GPL_3.0-blue.svg)](LICENSE)

AI-first графический редактор в духе Photoshop: слои, маски, выделения,
кисти — плюс нативная интеграция локальной сегментации SAM 2.1, хаба
генерации изображений polza.ai и AI-ассистента (Claude Code), который
управляет редактором через MCP. Интерфейс: русский (основной) и английский.

![Демонстрация Слойки](demo.gif)

Вы поддержите меня, если зарегистрируетесь по данной ссылке: [https://polza.ai/?referral=g5TV6XOHZU](https://polza.ai/?referral=g5TV6XOHZU)

## Возможности

### Редактор
- Слои: растровые, текстовые и **smart-слои** (перемещение, масштабирование
  и поворот без потерь качества, содержимое за краем холста не пропадает).
- **Стили фрагментов текста**: выделите часть текста — и задайте ей свой
  шрифт, размер, цвет и начертание, как в Photoshop.
- Маски слоёв, обтравочные маски, 8 режимов наложения.
- Отражение слоя по горизонтали/вертикали (ПКМ по слою) — вокруг центра
  содержимого, как в Photoshop.
- Выделения: прямоугольник, овал, лассо, волшебная палочка, кисти
  выделения — с живой растушёвкой и расширением/сжатием.
- Стили слоя: внешняя/внутренняя тень, свечение, **внешняя обводка**,
  наложение цвета, размытие по Гауссу, размытие в движении (учитывает
  поворот объекта). Обводка, свечение и расширение тени строятся по
  евклидову полю расстояний — идут от края равномерно во все стороны,
  включая углы.
- Кисти и ластик с нажимом пера; импорт кистей Krita (`.kpp`)
  и Photoshop (`.abr`).
- Инструмент кадрирования и изменение размера холста на лету.
- Вкладки документов с переносом слоёв drag-n-drop, история отмен
  с настраиваемым бюджетом памяти, автосохранение.

### Файлы
- Свой формат `.slojka` (zip, в духе OpenRaster).
- Импорт PSD и ORA, экспорт PNG / JPEG / WebP / ORA.

### AI (всё опционально — редактор полнофункционален и без этого)
- **Удаление фона**: ПКМ по слою → «Удалить фон» — локальная нейросеть
  (ISNet, ONNX Runtime), офлайн, Python не нужен, модель идёт в комплекте.
  У smart-слоёв фон удаляется у оригинала (трансформации без потерь),
  отмена — Ctrl+Z.
- **SAM 2.1**: клик по объекту — аккуратное выделение или маска слоя.
  Модель работает локально (CUDA или CPU), без интернета.
- **polza.ai** (нужен API-ключ): генерация изображений (Nano Banana,
  Seedream, GPT Image, Flux, Grok, Qwen и др.), апскейл, «удалить объект» /
  «заменить объект» по выделению — результат сам вставляется новым слоем.
  Кнопка «Фотобаш» 🎬 сводит всё видимое в одну картинку и пересобирает
  её моделью в цельную сцену (единый свет, камера, материалы).
  Очередь задач переживает перезапуски, стоимость видна по каждой задаче.
- **AI-ассистент**: встроенный терминал с Claude Code, подключённым к
  редактору через MCP (27 инструментов). Попросите текстом — он выделит,
  сгенерирует, нарисует и сохранит; все его правки отменяемы Ctrl+Z.
- Библиотека промтов с тегами.

## Установка

### Готовые сборки
На странице [Releases](../../releases) доступны:
- **Linux**: `Slojka-x.y.z.AppImage` — сделать исполняемым
  (`chmod +x`) и запустить;
- **Windows**: `Slojka-Setup-x.y.z.exe` — установщик (сам доустановит
  Python 3.11 и VC++ Redistributable, если их нет). Приложение не
  подписано сертификатом, поэтому SmartScreen покажет предупреждение —
  нажмите «Подробнее» → «Выполнить в любом случае».

### Из исходников
Требуется Node.js ≥ 20.19.

```bash
git clone https://github.com/HelpFreedom/slojka.git
cd slojka
npm install
npm run dev        # запуск в dev-режиме
```

Другие команды:

```bash
npm run smoke      # сборка + смоук-тест (WebGL2 + самотесты движка)
npm run typecheck  # проверка типов
npm test           # юнит-тесты
npm run audit      # проверка зависимостей на уязвимости
npm run dist       # сборка AppImage (packages/app/release/)
npm run dist -- --win   # сборка установщика Windows
```

### Включение AI-функций
1. **Локальный ИИ (SAM 2.1)**: нужен Python ≥ 3.10 (Windows-установщик
   Слойки сам доустановит Python 3.11 и Microsoft VC++ Redistributable,
   если их нет; на Linux поставьте python3 пакетным менеджером). Откройте
   ⚙ Настройки → «Локальный ИИ» → «Включить» (окружение ~15 МБ), затем
   «Установить SAM 2.1» (PyTorch ~2.5 ГБ, скачивается с явного согласия)
   и выберите модель (от 156 МБ). Всё ставится в изолированный venv.
2. **Генерация (polza.ai)**: вставьте API-ключ в панели «ИИ-генерация».
   Ключ хранится в системном хранилище секретов.
3. **AI-ассистент**: установите [Claude Code](https://claude.com/claude-code)
   (`npm install -g @anthropic-ai/claude-code`) и нажмите «🤖 AI-ассистент»
   в статусбаре. Если сеть через прокси — задайте его в
   ⚙ Настройки → «Сеть».

## Горячие клавиши

B кисть · E ластик · M/Shift+M выделение · L лассо · W палочка ·
A AI-выделение · T текст · C кадрирование · H рука ·
V перемещение/трансформация · [ ] размер кисти · Пробел панорама ·
Ctrl+Z/Shift+Z история · Ctrl+A выделить пиксели слоя ·
Ctrl+C/X/V копировать/вырезать/вставить слоем · Ctrl+J дубликат ·
Ctrl+E склеить · Ctrl+Shift+E свести видимое · Ctrl+D снять выделение ·
Ctrl+Shift+I инверсия · Del очистить · Ctrl+S сохранить

Хоткеи привязаны к физическим клавишам — работают в любой раскладке.

## Архитектура

```
packages/shared      бренд, модель документа, i18n (ru + en)
packages/engine      WebGL2-движок: композитор, кисти, выделения, стили, история
packages/app         Electron: main / preload / renderer (React)
packages/mcp-server  MCP-сервер для Claude Code
sidecar/             Python: SAM 2.1 + клиент polza.ai (опционально)
```

Подробное техническое описание всех подсистем — в
[TECHNICAL.md](TECHNICAL.md).

## Платформы

Первичная платформа — Linux (тестируется на Debian 11+). Код
кроссплатформенный: Windows поддерживается (шрифты, терминал, пути данных
и сборщик имеют платформенные ветки). Сборка под Windows на Linux-машине
требует wine.
